# 삼정학교 협업보드 (가칭)

학교 교사는 `@samjeong.ms.kr` Google 계정으로 협업 공간을 만들고, 학생은 Google 로그인 또는 익명으로 수업에 참여하는 웹서비스.

현재 단계는 요구사항 및 제작 계획 수립이다. 서비스 코드는 아직 없다.

- [제품 요구사항(PRD)](docs/PRD.md)
- [제작 지침 및 기술 설계](docs/IMPLEMENTATION.md)
- [병렬 개발 계획](docs/PARALLEL_PLAN.md)
- [개발 에이전트 작업 지침](AGENTS.md)

문서 기준일: 2026-10-12. Padlet의 기능을 참고하되 학교에 맞는 자체 서비스로 구현한다. 모든 기능의 완전한 일치가 검증된 상태는 아니며, 전체 기능 대장은 개발 중 지속 갱신한다.
