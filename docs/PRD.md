# 제품 요구사항(PRD)

버전: 0.2 / 2026-10-12 / 상태: 요구사항 기준선. 첫 구현 결과는 STATUS.md 참고

## 1. 제품 목표

삼정학교 교사가 수업용 협업 게시판, 자료 공유 공간, 모둠 활동, 공동 화이트보드와 학습 활동을 만들고 운영한다. 학생은 가입 절차 없이 익명으로 참여하거나 Google 계정으로 로그인하여 참여한다. 학교 교사는 Google 로그인 한 번으로 시작한다.

Padlet에 대응하는 폭넓은 기능을 최종 목표로 삼는다. 게시판 중심의 1차 출시 후 고급 게시판, 화이트보드, 학습 게임·AI 순으로 구현한다. 이 문서는 공개 자료를 바탕으로 한 초기 기능 범위이며 Padlet의 모든 기능을 빠짐없이 실사한 명세는 아니다. 브랜드·소스·디자인 자산은 자체 제작한다.

로그인은 신원 확인이며 게시판 접근 허가와 별개다. 로그인 학생도 유효한 초대가 필요하다. 초대받지 않은 학교 교사도 다른 교사의 비공개 게시판을 자동으로 열람하지 못한다.

학생의 로그인 여부와 화면에 이름을 보이는지는 별도 설정이다. 로그인 학생도 게시판에는 익명으로 표시할 수 있다. 교사에게는 계정 식별 정보가 보일 수 있다는 안내를 제공한다. 익명 참여자는 실명 확인 대상이 아니며 기기 변경·브라우저 데이터 삭제 후에는 본인 글 수정 권한을 자동 복구하지 않는다.

## 4. 대표 사용 흐름

1. 교사: Google 로그인 → 내 게시판 → 형식 선택 → 제목·활동 안내 작성 → 참여 방식 선택 → 참여 열기 → QR 확대 → 학생 글 확인·피드백 → 참여 종료·내보내기.
2. 익명 학생: QR 스캔 또는 참여 코드 입력 → 활동 안내 → 익명 참여 → 필요시 별명 입력 → 글·파일 제출 → 같은 브라우저에서 수정.
3. 로그인 학생: QR → Google 로그인 → 원래 활동으로 복귀 → 작성 → 로그인 계정으로 자신의 글 확인. 학생 로그인 후 교사 대시보드로 보내지 않는다.
4. 모둠: 교사가 모둠별 페이지 생성 → 각 QR 배부 → 배정된 모둠 범위에서 활동 → 교사가 전체 결과 확인.
5. 제출 전용: QR → 문제·제출 양식 → 제출 → 본인 제출 확인. 다른 학생 답안은 열람 불가.

P0 공동 교사는 소유 교사가 지정하는 고정 편집자 역할만 지원하며 P1에서 세분화한다. P0 섹션은 정리용으로 같은 게시판 읽기 권한을 공유한다. 모둠별 데이터 격리는 P1 GROUP-01에서 제공하며, 그 전에는 별도 게시판으로 운영한다. P0 인쇄 PDF는 브라우저 인쇄 기능이며 서버 PDF·이미지 생성은 P1에서 다룬다.

전체 기능 대응 완료는 단계 완료와 다르다. 각 기능별 공식 근거·대응 화면·차이·테스트·완료 상태를 기록한 기능 대장을 갱신하고, 미실사·미지원 항목을 0개로 정리하거나 제품 책임자가 차이를 명시적으로 수용했을 때에만 완전 대응 여부를 판단한다. 현재 P3 목록도 실사 확장이 필요하다.

## 6. 공유 및 QR 상세

공유 가능한 활동 페이지에는 동일한 위치에 `공유` 버튼을 둔다. 교사용 관리·계정·승인 대기 화면은 공유 대상이 아니다. 교사 편집 화면에서 공유하면 학생용 보기로 연결한다.

|페이지|QR 목적지|범위|
|---|---|---|
|게시판|학생용 게시판|게시판에서 허용한 읽기·쓰기|
|개별 게시글|해당 글 상세|대상 글 접근, 상위 게시판 권한 재확인|
|섹션|해당 섹션 위치|P0는 게시판 전체 읽기 권한과 동일|
|모둠 활동|그룹 활동 페이지|P1부터 지정 그룹만|
|제출 양식|제출 화면|작성·본인 제출 확인만|
|화이트보드 카드·게임|해당 활동|P2·P3 단계에 맞춰 추가|

공유 창은 QR, 링크 복사, PNG 다운로드, 전체 화면 표시, 인쇄, 참여 코드와 만료·개방 상태를 제공한다. 빔프로젝터용 전체 화면에는 활동 제목·큰 QR·짧은 코드·참여 안내를 표시한다. QR은 서버에 등록된 고엔트로피 공유 링크를 담고 이메일·인증 토큰·관리자 주소는 담지 않는다. 짧은 참여 코드는 유효 기간과 입력 횟수 제한을 둔다.

공유 링크는 대상·읽기/작성 범위·만료·상태·버전을 갖는다. 기본 권한을 넘는 권한을 주지 않는다. 회수 시 기존 링크·QR·참여 코드로 신규 입장할 수 없고 해당 링크로 발급된 기존 참여 권한도 철회한다. 다른 유효한 초대가 있다면 그 초대의 범위만 유지한다. 비공개 대상의 제목이나 썸네일도 인증 전 미리보기로 노출하지 않는다.

익명 참여가 열린 링크는 전달받은 외부인도 접근할 수 있다. 교사는 참여 시간 제한·코드 재발급·로그인 필수·허용 계정 목록으로 통제할 수 있다. 익명 사용자의 동일인 식별이나 영구 차단은 보장하지 않으며 화면에서 실제 인원 대신 참여 세션 수로 표시한다.

## 7. 게시판 상태와 공개 규칙

- 게시판 상태: `draft → open → closed → archived`, 휴지통은 별도 `deletedAt`. 닫힘은 학생 쓰기 중지이며 읽기는 기존 공유 정책을 따른다. 공유 회수는 읽기도 차단한다.
- 글 상태: `pending / published / rejected / hidden / deleted`. 승인 필요 게시판의 수정 글은 재승인 전 학생 전체에 공개하지 않는다.
- 학생은 공개 글과 본인 대기·반려 글만 본다. 제출 전용 페이지는 본인 제출만 본다. 미공개 파일·댓글·검색·집계에서도 동일 규칙을 적용한다.
- 교사의 차단·삭제·공유 회수는 API, 실시간 구독, 파일 다운로드에도 반영한다. 이미 내려받은 내용은 회수할 수 없다.

## 8. 화면 구성

로그인/참여 코드 입력, 교사 대시보드, 게시판 생성·설정, 학생용 게시판, 게시글 상세·작성, 제출 페이지, 공유·QR 전체 화면, 승인 관리, 학교 관리 화면이 P0 범위다. 모바일은 작성 버튼과 QR 진입을 우선하고, 교실 화면은 카드 가독성·QR 크기를 우선한다. 한글 UI를 기본으로 하며 키보드 탐색, 초점 표시, 이미지 대체 텍스트, 드래그의 버튼 대안을 제공한다.

## 9. 품질·운영 목표와 제안 한도

무료 시범 배포는 한두 학급부터 검증한다. 사진은 자동 압축 후 1MB 이하·글당 5개, 게시판 100MB·교사 200MB·학교 800MB로 제한한다. PDF·일반 문서·영상은 링크로 공유한다. 아래의 학교 전체 500세션·20MB 일반 파일은 확장 목표이며 현재 무료 구성의 보장 범위가 아니다. Supabase Free의 실시간 동시 연결 200개, DB 500MB, 파일 1GB, 일반 전송량 월 5GB 및 Cloudflare API/쿼리/CPU 한도를 별도로 계측한다. 최신 한도와 실행 지침은 DEPLOY_FREE.md를 따른다.

무료 실시간 채널은 최대 60초짜리 권한으로 빈 알림만 받는다. 내용·파일·새 토큰은 요청마다 현재 권한을 검사한다. 화면은 변경 알림과 45초 재확인으로 갱신하며, 무료 구성의 회수 시점 기준과 기존 SSE 1초 검증을 구분한다.

## 10. 출시 수용 기준

1. 허용된 교사가 로그인하고 게시판을 생성한다. 다른 도메인과 정지 계정은 API 직접 호출에서도 교사 작업이 거부된다.
2. 학생 Google 로그인·익명 참여 모두 동일 QR에서 시작하며, 로그인 후 원래 페이지로 돌아온다. 로그인 필수 게시판에서는 익명이 거부된다.
3. QR이 게시판·글·섹션·제출 페이지의 정확한 학생용 목적지로 연결된다. 만료·회수·삭제 링크는 접근이 거부된다.
4. 40명 동시 수업에서 게시·수정·댓글·승인 상태가 동기화되고 재시도 시 중복 글이 생기지 않는다.
5. 학생이 타인 글 수정, 다른 게시판 조회, 대기 글·첨부 열람, 교사 역할 위조를 시도해도 거부된다.
6. 제출 전용 참여자는 목록 API·실시간 구독·파일 URL로도 타인 답안을 얻을 수 없다.
7. 익명 작성자는 같은 세션에서 본인 글을 수정한다. 세션 소실 시 복구 제한 안내가 나온다.
8. 게시판 닫기·참여자 차단·공유 회수 후 이미 열린 화면의 다음 요청과 실시간 연결에도 권한 변경이 적용된다.
9. 업로드 실패·초과·네트워크 단절 시 재시도와 상태 안내가 제공된다. CSV·인쇄 결과의 한글과 시각이 올바르다.
10. Android Chrome·iOS Safari의 QR 진입, PC Chrome·Edge, 키보드 탐색을 검증하고 테스트 백업을 실제 복원한다.
