# 실행 계약 v1

공통 API는 `packages/contracts/index.ts`, 스키마는 `packages/db/schema.ts`다. DB는 `await getDb()`로 얻고 `all<T>`, `one<T>`, `run`, `transaction(fn)`을 사용한다. SQL은 PostgreSQL `$1` 매개변수 방식이다. id/now/emit/audit 헬퍼가 있다. 개발은 PGlite, 운영은 DATABASE_URL PostgreSQL이다.

모듈 별 `handleAuth`, `handleBoards`, `handleShares`는 `(req:Request, segments:string[]) => Promise<Response|null>`로 내보낸다. segments는 `/api`를 제외한 경로다. 권한·입력 오류는 common/http의 ApiError 또는 fail로 throw한다. root dispatcher가 잡는다. JSON 응답은 json(data) → `{data}`. 변경 요청의 Origin 검증은 dispatcher에서 수행한다. 다른 담당은 공통 파일을 수정하지 않는다.

A exports (`@server/auth`): `getPrincipal(req):Promise<Principal|null>`, `requirePrincipal(req):Promise<Principal>`, `createAnonymousSession(displayName):Promise<{principal:Principal,cookie:string}>`, `handleAuth`.
A exports (`@server/policy`): `canManage(db,principal,board):Promise<boolean>`, `boardAccess(db,principal,boardId):Promise<{board:Board,can_manage:boolean,can_write:boolean,submission_only:boolean,shares:Share[]}>`, `canReadPost(access,principal,post):boolean`, `requireTeacher(principal):void`. boardAccess fails if unauthorized. Student needs valid, nonblocked, unexpired share/version participation; teacher owner/editor even closed; students draft/archived/deleted denied. share post limits visible post; board/section shares allow all published+own; submission only own. mixed share grant union.

B exports (`@server/boards`): `handleBoards`, `getBoardView(principal,boardId):Promise<BoardView>`. C and D can call getBoardView for DTOs. B UI `Dashboard` no props, `BoardWorkspace` props `{boardId:string;postId?:string;sectionId?:string;submission?:boolean}`. B uses C ShareDialog directly if available or parent integration adds it. Don't import placeholder nonexistent modules for compilation.

C exports (`@server/shares`): `handleShares` for POST /api/shares, GET /api/boards/:id/shares, revoke, POST /api/join, GET /api/share-preview?token=. POST join input `{token?:string,code?:string,mode:'anonymous'|'login',display_name?:string}`; anonymous creation through A. Response `{board_id,target_type,target_id,destination}`; Set-Cookie when creating session. Preview only returns participation mode after token validation, no private title/content. UI `JoinPage` props `{token?:string}`; `ShareDialog` props `{boardId:string;targetType?:Share['target_type'];targetId?:string;title:string;onClose:()=>void}`.

D owns app route wrappers, common styling, media, realtime, admin, exports, root configs/db/contracts/dependencies. File upload `POST /api/boards/:id/attachments` multipart(file), response attachment metadata id; `GET /api/attachments/:id/content`. B sends attachment_ids on post create/update and displays attachments via authorized URL. Admin `/api/admin/teachers` GET/PATCH plus `/api/admin/summary`, `/api/admin/audit` and board transfer.
