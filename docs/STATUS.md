## 설계 구체화

- 개발 DB는 WASM PostgreSQL인 PGlite, 운영은 `pg` 드라이버와 `DATABASE_URL`을 사용한다. 운영 모드에서 개발 DB로 자동 대체하지 않는다.
- 정규화된 관계형 SQL 테이블과 트랜잭션을 사용한다. 첫 스키마는 `packages/db/schema.ts`에 있으며 이후 변경은 버전 마이그레이션 체계를 추가한다.
- 파일은 비공개 로컬 볼륨과 다운로드 프록시를 사용한다. 운영 배포에서 영속 볼륨과 ClamAV 검사를 구성한다. 객체 저장소 어댑터·고아 파일 정리·검사 재시도 작업자는 후속 운영 작업이다.
- 실시간 전달은 무효화 이벤트만 전달한다. 연결 시작 및 변경 시 최신 BoardView를 재조회하므로 게시글 이벤트 재생 로그를 학생에게 노출하지 않는다.
- 서버 파일 조회마다 현재 권한을 확인한다. SSE 권한 철회는 약 1초 내 재확인하며 이미 내려받은 내용은 회수할 수 없다.
- QR 링크 원문·코드는 생성 응답에서만 전달한다. 기존 초대는 목록·회수 가능하며 다시 표시하려면 새 초대를 만든다.

## 검증 기록

최종 npm run check 통과: 타입 검사 오류 0, 린트 경고/오류 0, 자동 테스트 60개 통과(인증·권한 24 / 게시판 14 / 공유 11 / 통합 11), Next.js 프로덕션 빌드 성공. npm 설치 시 의존성 감사 결과 취약점 0개.

통합 API 테스트에서 교사 게시판 생성→참여 개방→익명 입장→비공개 파일 업로드→승인 대기→교사 승인→댓글·좋아요→차단/해제→닫기→공유 회수→파일 접근 거부를 검증한다. 별도 테스트로 40세션의 동시 글 저장, 열린 SSE 연결의 권한 회수, DB 백업 복원을 확인한다. 이는 단일 개발 DB에서의 API 검증이며 학교망의 응답시간 목표나 전체 500세션 목표 달성을 의미하지 않는다.

브라우저·휴대전화·학교 Google 실제 계정·실제 운영 PostgreSQL·ClamAV 실환경·학교망·파일 포함 운영 복원은 아직 검증하지 못했다. 이 실행 환경은 로컬 서버 포트 열기를 허용하지 않았으며, 서버 실행 권한 요청도 정책에서 자동 거부되어 브라우저 검증을 수행하지 않았다. OAuth 비밀값은 제공받지 않았고 코드에 넣지 않았다.
